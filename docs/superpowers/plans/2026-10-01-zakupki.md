# Закупки Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a «Закупки» sidebar section (Приходные накладные, Накладная, Поставщики, supplier statement) on Salesdoc data, plus empty «Номенклатура» and «Отчёты» pages, moving the old receipt and supplier pages there.

**Architecture:** Two API changes in the existing NestJS modules — filters on `GET /api/warehouse/purchases` (WarehouseService) and a new `GET /api/suppliers` plus a supplier filter on `GET /api/supplier/statement` (SettlementsService). The web gets new App Router pages under `app/zakupki`, a sidebar that supports one level of sub-items, placeholder pages, and redirects from the old addresses.

**Tech Stack:** NestJS 12 + Prisma 7 (vitest, test DB), Next.js 16 App Router server components, shadcn/Base UI, existing shared components.

**Spec:** `docs/superpowers/specs/2026-10-01-zakupki-design.md`

## Global Constraints

- Data source is Salesdoc only; pages are read-only (no create/edit).
- Window = current month (parent spec §4); periods before the window start return 400 and the period picker stays on screen.
- Money from the API is a 2-dp string; debt sign follows 1C «Долг (+ нам, − мы)»: what we owe a supplier is negative.
- Every user-visible word goes through `t()` with ru and uz in `apps/web/src/i18n/messages.ts`, same key order in both.
- Shared components only: `Select` (`@/components/app/select`), `PagePeriod`, `StickyToolbar`, `PageHeader`, `ApiError`, `Text`, `Money`, `StatementTable`; no raw `<select>`/checkbox.
- Old route files are kept as redirects with a comment naming the new page (memory rule: superseded code is not deleted outright).
- Imports in `apps/api` end in `.js`. Commits end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
- API changes need `npx nest build` + restarting the "distribution-finance API" window before the browser check.

## Review Focus

- **A number search containing `%` or `_`** must match those characters literally, not act as a wildcard — test in Task 1.
- **A supplier id that appears on receipts but not in Salesdoc's supplier list** must still be listed, named by its id — test in Task 2.
- **A supplier with no receipts in the window** must show `0.00` debt, not `-0.00` — test in Task 2.
- **An unknown накладная id** in the address must show the API's message under the page header, not crash — browser check in Task 4.
- **Old bookmarks** (`/supplier`, `/warehouse?tab=purchases`, `/warehouse/purchases/<id>`) must land on the new pages, keeping the period — browser check in Tasks 4 and 5.

  async purchases(p: Period, q: { supplier?: string; warehouse?: string; search?: string } = {}) {
    const n = await this.names();
    const suppliers = await this.prisma.supplier.findMany({
      orderBy: { name: 'asc' },
      select: { sdId: true, name: true },
    });
    // Escape LIKE wildcards so a typed % or _ matches itself.
    const search = q.search?.replace(/[\\%_]/g, (c) => `\\${c}`);
    const list = await this.prisma.purchase.findMany({
      where: {
        date: { gte: p.from, lt: p.toExclusive },
        ...(q.supplier ? { supplierSdId: q.supplier } : {}),
        ...(q.warehouse ? { warehouseSdId: q.warehouse } : {}),
        ...(search ? { sdId: { contains: search, mode: 'insensitive' } } : {}),
      },
      orderBy: [{ date: 'desc' }, { sdId: 'desc' }],
      include: { _count: { select: { lines: true } } },
    });
    const total = list.reduce((sum, x) => sum.plus(x.total), new Prisma.Decimal(0));
    return {
      total: s2(total),
      filters: { suppliers, warehouses: n.warehouses },
      rows: list.map((x) => ({
        sdId: x.sdId,
        date: x.date.toISOString(),
        warehouseSdId: x.warehouseSdId,
        warehouseName: x.warehouseSdId ? (n.warehouse.get(x.warehouseSdId) ?? null) : null,
        supplierSdId: x.supplierSdId,
        supplierName: x.supplierSdId ? (n.supplier.get(x.supplierSdId) ?? null) : null,
        lineCount: x._count.lines,
        total: s2(x.total),
      })),
    };
  }

```ts
  /** §4.2 goods side; supplier payments arrive with the cash-entries plan. */
  async supplierStatement(p: Period, supplierSdId?: string) {
    const only = supplierSdId ? Prisma.sql`AND "supplierSdId" = ${supplierSdId}` : Prisma.empty;
    const [{ opening }] = await this.prisma.$queryRaw<Array<{ opening: Dec | null }>>`
      SELECT SUM(total) AS opening FROM "Purchase"
      WHERE date >= ${p.windowStart}::timestamp AND date < ${p.fromDay}::timestamp ${only}`;
    const purchases = await this.prisma.purchase.findMany({
      where: {
        date: { gte: p.from, lt: p.toExclusive },
        ...(supplierSdId ? { supplierSdId } : {}),
      },
      orderBy: [{ date: 'asc' }, { sdId: 'asc' }],
    });
    const warehouses = new Map(
      (await this.prisma.warehouse.findMany()).map((w) => [w.sdId, w.name]),
    );
    let balance = new Prisma.Decimal(opening ?? 0);
    let received = new Prisma.Decimal(0);
    const rows = purchases.map((pu) => {
      balance = balance.plus(pu.total);
      received = received.plus(pu.total);
      return {
        kind: 'purchase' as const,
        sdId: pu.sdId,
        date: pu.date.toISOString(),
        warehouseName: pu.warehouseSdId ? (warehouses.get(pu.warehouseSdId) ?? null) : null,
        amount: s(pu.total),
        balance: s(balance),
      };
    });
    return { opening: s(opening), received: s(received), paid: s(0), closing: s(balance), rows };
  }

  /**
   * One row per supplier (Salesdoc's list plus any supplier id found on a
   * receipt). debt follows 1C «Долг (+ нам, − мы)»: what we owe is negative.
   */
  async suppliers(p: Period) {
    const [listed, sums] = await Promise.all([
      this.prisma.supplier.findMany({ select: { sdId: true, name: true } }),
      this.prisma.$queryRaw<Array<{ supplier: string; received: Dec; balance: Dec }>>`
        SELECT "supplierSdId" AS supplier,
          SUM(CASE WHEN date >= ${p.fromDay}::timestamp THEN total ELSE 0 END) AS received,
          SUM(total) AS balance
        FROM "Purchase"
        WHERE "supplierSdId" IS NOT NULL
          AND date >= ${p.windowStart}::timestamp AND date < ${p.toExclusiveDay}::timestamp
        GROUP BY "supplierSdId"`,
    ]);
    const names = new Map(listed.map((x) => [x.sdId, x.name]));
    const bySupplier = new Map(sums.map((r) => [r.supplier, r]));
    const ids = new Set([...names.keys(), ...bySupplier.keys()]);
    const rows = [...ids].map((sdId) => {
      const r = bySupplier.get(sdId);
      const balance = new Prisma.Decimal(r?.balance ?? 0);
      return {
        sdId,
        name: names.get(sdId) ?? sdId,
        received: s(r?.received),
        paid: s(0),
        debt: balance.isZero() ? s(0) : s(balance.neg()),
      };
    });
    rows.sort((a, b) => a.name.localeCompare(b.name));
    return { rows };
  }
```

"use client";

import Link from "next/link";
import { usePathname } from "next/navigation";
import { cn } from "@/lib/utils";

export interface NavItem {
  href: string;
  label: string;
  /** Path prefix that makes this item active (defaults to href). */
  match?: string;
  children?: NavItem[];
}

export function Sidebar({ title, items, footer }: { title: string; items: NavItem[]; footer: React.ReactNode }) {
  const pathname = usePathname();
  const isActive = (i: NavItem) => {
    const m = i.match ?? i.href;
    return m === "/" ? pathname === "/" : pathname.startsWith(m);
  };
  const link = (i: NavItem, active: boolean, sub = false) => (
    <Link
      key={i.href + i.label}
      href={i.href}
      className={cn(
        "rounded-md px-3 py-2 text-sm transition active:scale-[0.98]",
        sub && "md:ml-3 md:py-1.5",
        active ? "bg-foreground text-background" : "hover:bg-muted",
      )}
    >
      {i.label}
    </Link>
  );
  return (
    <aside className="flex shrink-0 flex-col gap-4 border-b bg-muted/30 p-4 md:sticky md:top-0 md:h-screen md:w-56 md:overflow-y-auto md:border-r md:border-b-0">
      <span className="font-semibold">{title}</span>
      <nav className="flex flex-wrap gap-1 md:flex-col">
        {items.map((i) =>
          i.children ? (
            <div key={i.label} className="flex flex-wrap gap-1 md:flex-col">
              <Link
                href={i.href}
                className={cn(
                  "rounded-md px-3 py-2 text-sm transition active:scale-[0.98] hover:bg-muted",
                  isActive(i) && "font-semibold",
                )}
              >
                {i.label}
              </Link>
              {i.children.map((c) => link(c, isActive(c), true))}
            </div>
          ) : (
            link(i, isActive(i))
          ),
        )}
      </nav>
      <div className="md:mt-auto">{footer}</div>
    </aside>
  );
}
